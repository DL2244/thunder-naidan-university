# ⚡ 雷霆奶蛋大学

以圆滚滚的黄色奶蛋为吉祥物，打造的一所充满好奇、勇气与快乐的虚构大学。

> 以好奇为起点，让热爱有回响。

## 🌐 在线体验

https://reliable-crisp-2e28c6.netlify.app

## ✨ 网站特色

- **星空入校仪式**：渐变星空背景、圆形奶蛋校徽、环形倒计时，支持暂停和立即进入。
- **校园首页**：认识雷奶大，探索校园理念与特色内容。
- **院系探索**：奇思妙想学院、雷霆行动学院、快乐生活学院。
- **校园生活**：放空俱乐部、脑洞放映室、草坪音乐会等创意生活提案。
- **奶蛋来信**：校园公告、创意活动与治愈专栏。
- **专属入学通知书**：输入昵称即可生成纪念通知书，支持截图收藏。
- **氛围音效**：可手动开启或关闭。
- **响应式布局**：适配电脑与手机浏览。

## 🛠️ 技术栈

- HTML5
- CSS3
- 原生 JavaScript
- Netlify 静态网站托管

无需安装依赖，无需构建。

## 📁 项目结构

网站源码位于仓库中的“雷霆奶蛋大学-上传目录”文件夹：

雷霆奶蛋大学-上传目录/
├── index.html          # 页面结构
├── style.css           # 样式与响应式布局
├── app.js              # 页面交互
├── README.md           # 项目说明
└── assets/
    └── mascot.png      # 奶蛋吉祥物图片

## 🚀 本地运行

下载仓库并解压，进入源码目录，用浏览器打开 index.html 即可查看。

## 📦 网站部署

将包含 index.html、style.css、app.js 和 assets 的源码目录上传至 Netlify，即可部署为静态网站。

目前采用手动上传部署。修改 GitHub 文件后，需要在原 Netlify 项目中重新上传更新后的目录，线上网站才会同步更新。

## 🎨 视觉设计

入场页采用星空渐变与环形校徽，校园首页以深蓝、奶油白和奶蛋黄为主色。

奶蛋吉祥物图片由 AI 根据参考形象生成，网站设计与代码在 Codex 协助下完成。

## 🔒 隐私说明

入学通知书在浏览器本地生成，网站代码不会将输入的昵称上传至服务器。
