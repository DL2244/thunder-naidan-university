# 雷霆奶蛋大学 ⚡

一所以奶蛋为吉祥物的虚构校园网站，以好奇、勇气和快乐为主题。

[在线体验](https://reliable-crisp-2e28c6.netlify.app/)

## 功能

- 星空入校仪式、校园首页和入学通知书预览。
- 奇思妙想、雷霆行动、快乐生活三个学院，独立分类、搜索与内容详情。
- 思考、剑盾和开心三款奶蛋形象。
- 本机投稿草稿保存与 JSON 导出。
- 社区前端支持邮箱登录、唯一账号名、投稿和文字评论；账号名每个北京时间自然月可改一次，历史署名保留。
- 社区稿件通过后公开，作者和有权限的账号可进行对应管理操作；具体权限由后端校验。

## 本地预览

网站文件位于“雷霆奶蛋大学-上传目录”文件夹。下载仓库后，直接打开该目录里的 index.html 即可浏览静态页面、示例内容、编辑本机草稿和生成通知书预览。使用原生 HTML、CSS 与 JavaScript，无需安装依赖或构建。

## 社区配置与隐私

本仓库中的 community-config.js 故意留空，因此新克隆的副本不会连接原站数据库，云端登录、投稿和评论暂不可用。

需要部署社区时，请先自行配置兼容后端，再在单独的部署副本中填写自己的项目地址与前端 Publishable key。不要将部署配置覆盖后直接提交回公共仓库；不要填写管理员密钥。

本公开源码不包含管理员名单、私人邮箱、SMTP 授权码、数据库密码、服务端密钥、登录会话、真实用户投稿／评论数据、数据库安装脚本或本地排查记录。图片只包含网站吉祥物，并移除了 PNG 文本与 Exif 元数据。

登录确认账号名、发表稿件与评论会向所配置的社区服务上传相应资料；未启用社区时，本机草稿和通知书预览留在浏览器中。

## 部署

将包含 index.html、全部 JS／CSS 与 assets 的整个网站目录上传到静态托管服务。当前采用手动部署，修改 GitHub 文件不会自动更新原 Netlify 网站。

本项目为创意虚构校园，院系、活动和通知书不代表真实招生或学历。吉祥物图片由 AI 根据参考形象生成。
