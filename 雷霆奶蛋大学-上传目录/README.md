# 雷霆奶蛋大学 ⚡

以黄色奶蛋为吉祥物的创意大学网站，包含星空入场、环形倒计时、校园首页、院系探索及入学通知书生成。

在线访问：https://reliable-crisp-2e28c6.netlify.app

## 本地查看

直接用浏览器打开 `index.html`。所有业务交互均在浏览器本地执行，昵称不会上传。

## 文件

- `index.html`：页面结构
- `style.css`：桌面与移动端样式
- `app.js`：入场、弹窗、通知书及氛围音交互
- `assets/mascot.png`：奶蛋吉祥物图片，使用内置 imagegen 根据参考形象生成

## 部署

将整个目录上传至 Netlify 静态托管，无需安装依赖或构建。

本网站为创意虚构校园，院系、活动和通知书不代表真实招生或学历。
